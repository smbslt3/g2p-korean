# 아키텍처

## 처리 순서

```text
원문 → G2P.__call__ 또는 G2P.convert
→ NFC → normalize_numbers(입력 보존 더미)
→ 영문 관용 읽기 또는 철자 읽기·한국어 표면 발음 생성
→ TTS
```

G2P는 숫자 입력도 보존하며 숫자 모델을 요청하지 않습니다. 숫자가 남으면
경고와 `complete=False`로 보고합니다. `normalize` 불리언은 이전 호출
호환용이며 두 값 모두 같은 동작입니다. 숫자를 읽으려면 앞단에서 `16%`를
`십육 퍼센트`로 만들고, G2P가 `심뉵 퍼센트`로 바꿉니다.

아래 노멀라이저는 기존 독립 도구로 유지하며 G2P 호출 경로에서 제외합니다.

## 노멀라이저

```text
NFC·입력 검증
→ 보호 구간 탐지
→ 우선순위 토큰 스캔
→ 확정 규칙 변환
→ 지정한 외부 HF 숫자 실행기로 필요한 숫자 문맥 판별
→ 보존 정책·진단
```

통화·날짜·시간·범위처럼 표기가 읽기를 확정하는 토큰은 규칙이 담당합니다. 숫자
판별 모델은 카운터와 맨숫자처럼 문맥이 필요한 후보에만 개입합니다. 모델과 추론 코드는
별도 HF 묶음으로 받고 숫자 구간의 앞뒤 문맥을 사용합니다. 기본 생성자는 모델 없이
규칙으로 실행하며, 외부 실행기 실패 시 규칙 결과와 진단을 반환합니다.

문자열 API는 원문 span 생성을 생략하고, 일반 한글 문장은 토큰 스캐너도 건너뜁니다.
노멀라이저의 상세 `convert()`만 원문 좌표·rewrite·진단을 만듭니다.

`normalizer/units.py`는 단위 읽기표, `grammar.py`는 우선순위 토큰 문법,
`renderers.py`는 문맥과 무관한 숫자·단위·달력 변환, `policy.py`는 보존·진단·오류
정책을 담당합니다. `engine.py`는 사용자 사전과 문맥 판별을 조정합니다. 호출별
`_RunState`가 모든 보호·변환 구간의 출력 길이, rewrite, 진단과 완료 상태를 모으며,
일반 한글의 빠른 경로도 같은 출력 길이 검증을 거칩니다.

## G2P

```text
NFC·입력 검증
→ 영문·숫자·미지원 문자 분류
→ 주소·이메일·코드 범위를 원문 좌표로 탐지
→ 명확한 독립 영문 표현은 공유 읽기표에서 조회
→ 미등록·모호한 영문과 구조 안의 영문은 알파벳 이름으로 변환
→ 숫자·미지원 문자 HARD 경계 병합
→ Kiwi 형태소 분석으로 규칙의 문맥 확인
→ 한국어 음운 규칙 적용
→ 최종 출력 검증
```

`english/context.py`는 독립 단어·약어인지 확인합니다. 조회는 대소문자를 구분하지
않으며 NFKC 대응 표기도 처리합니다. 등록 단어라도 URL·이메일·경로·인라인 코드나
결합 식별자 안에 있으면 글자 이름으로 읽습니다. URL 기호를 `콜론`, `슬래시`,
`점`처럼 발화하지 않고 원래 문장부호를 보존합니다. 따라서 URL은 알파벳 부분만
철자화되고 나머지 구분 기호는 그대로 남습니다.

`english/conventional.py`가 G2P와 기존 독립 노멀라이저가 공유하는 선별된 영어 읽기표를
제공하며, `normalizer/conventional_english.py`는 호환용 재내보내기를 제공합니다.
NASA·laser·coffee·TV처럼 읽기가 명확한 등록 항목에는 `english.conventional.v1`
규칙 ID를 내부 `Pipeline.run()` rewrite trace에 기록한 뒤 한국어 음운 규칙을 적용합니다.
이 rewrite 목록은 공개 `G2PResult`나 진단 report에 노출되지 않습니다. 이 표는 모든
영어의 공식 표준 발음을 포괄하는 사전이 아닙니다. 잔여 숫자는 `unconverted_numeric` 진단과 함께
보존하고 미완료로 보고합니다. G2P는 사용자 사전이나 숫자 모델을 호출하지 않으며,
기존 노멀라이저의 더 풍부한 숫자·URL·기호 처리는 G2P 경로와 독립적으로 유지됩니다.

`english/structures.py`는 문자별 NFKC 탐지용 문자열을 만들고 원문 위치로 투영합니다.
프로토콜 없는 도메인·국제화 도메인·쿼리·여러 줄 코드 울타리도 관용 읽기에서
제외합니다. 이 범위는 영어 사전 적용만 제한하므로 숫자·미지원 문자의 진단을
숨기지 않습니다. 일반 한글 문자경계는 조사와 복합 표기를 위해 허용하고,
영문에 붙은 결합문자·형식문자·다른 문자 체계는 식별자 일부로 봅니다.
추가된 고유 명칭의 공식 한국어 표기 근거와 보류 이유는
`ENGLISH_NAME_CANDIDATES_20261023.json`에 기록합니다.

형태소 경계 annotation은 PyPI 배포판의 공개
`Kiwi.tokenize(split_complex=True, saisiot=True)` 결과를 사용합니다.
2026-10-25부터 검증 대상은 최신 안정 버전 `kiwipiepy==0.24.1` 하나로 통일합니다.
개발 잠금 파일의 `kiwipiepy-model`은 `0.24.0`입니다. 아래의 0.23.2 결과는 당시의
과거 기록이며 현재 지원 버전이나 회귀 검사 대상을 뜻하지 않습니다.
고립형 `밭이랑`과 `서울역도`에는 서로 다른 형태소 해석이 가능하므로 의도한 분석을
명시한 엔진 검사와 뜻을 구분하는 문장의 실제 Kiwi 검사를 함께 사용합니다.
과거에 두 고립형의 특정 해석만 요구해 발생한 실패 기록은 별도로 보존합니다.
활용형 분해로 겹치는 원문 좌표를 공유하는 token은 태그를 합칩니다. 길이 0인 형태소
태그는 같은 시작점의 다음 원문 구간에 붙이고, 표면형은 원문에서 복원해 비중첩
annotation으로 만듭니다. 이미 덮인 좌표의 길이 0 태그는 해당 token에 합칩니다.

`analysis_features.py`는 같은 분석 호출에서 얻은 기본형·품사 쌍을 원문 구간별로
보존합니다. 따라서 `폈`처럼 태그가 합쳐진 표면형에서도 `펴/VV + 었/EP`를 사용할
수 있습니다. `AnalysisToken.morphemes`는 불변 튜플이며 기본값은 빈 튜플입니다.
이 내부 토큰의 동등성·해시와 직접 `to_dict()` 결과에는 새 필드가 포함됩니다.
공개 `G2PResult`에는 형태소 필드를 추가하지 않습니다.

`korean/surface_proof.py`는 원형별 NFD 자모와 출현 인덱스를 보존하며 표면을
재생성합니다. 직접 자모 결합, 정규 모음 축약·ㅡ 탈락, 명시된 `이/XSV` 파생과
여러 활용 경계의 합성을 검증하고, 각 출현의 재생성 범위를 실제 원시 범위와
대조합니다. 연결 어미 뒤의 `VX`는 별도의 활용 어간으로 시작하여 모음 조화의
문맥을 다시 잡습니다. 어휘 원형을 임의로 내부 분해하거나 편집 거리로 맞추지 않습니다.

전체 표면 증명은 파생어 적격성, 단독 자모 소유, 형식 부착에서 공유합니다.
공동 모음은 여러 원형의 유래를 유지합니다. 형식 부착은 그 모든 유래가 허용된
접미사·어미 사슬 안에 있는지 별도로 검사하며, 단독 소유자로 바꾸지 않습니다.
이 사슬 판정만으로 구개음화나 계사 조건을 확대하지 않습니다. 원형 없는 결합
태그나 길이 0의 어미 표시는 증명 불충분과 실제 모순을 구별하여 처리합니다.
새 증명이 불가능해도 기존의 제한된 정확한 어미 말단 대응은 보존합니다.

`korean/semantic_policy.py`는 등록한 동형 명사의 의미별 어휘 속성과 관계 판정기를
분리합니다. 실제 격 조사, 기본형을 보존한 첫 술어, 직접 소유·부분 관계와 관형절을
사용하며, 선택 결과는 해당 출현의 원문 좌표에만 적용합니다. 침구 `잠자리`와 강변
`강가`는 합성 경계를, 물리적 실체 `물질`은 한자어 속성을 기존 음운 규칙에 전달합니다.
완성 발음이나 문장 전체를 치환하는 표를 사용하지 않습니다. 선택기는 어휘 구조를
확장하기 전에 실행하므로 확장 토큰에서 기본형 정보가 사라져도 선택에는 영향을
주지 않습니다. 형태소 분석을 추가로 호출하지 않습니다.

`고가·사법·소수·시가`도 의미별 속성을 분리합니다. 가격·사법 분야·수량·문학
분류는 선언한 논항, 계사, 소속, 명명 관계로 연결하며, 단순한 주변 주제어만으로
뜻을 고르지 않습니다. 가격 뜻에는 내부 경음화 경계를 전달하고, 조사 결합형은
기존 음운 규칙으로 처리합니다. 자연수 약수의 정확한 두 개 수량은 소수(素數)의
근거가 되지만, 대략적인 수량이나 일반적인 수학 문맥은 충분한 근거로 삼지 않습니다.

거래 구문의 가격과 수신자를 구별하며, `시가에`처럼 시장가격과 배우자 집안
해석이 함께 가능한 논항은 보류합니다. `바탕·근거·기준`의 목적어는 해당 부사
구문에 속한 것으로 처리합니다. 소속 관계의 의미는 호환되는 핵어에만 전달하여
민법을 포함하는 임의의 책을 사법으로 분류하지 않습니다. 부정 대비도 선언된
가격·수량 척도에 한하며, 모든 `X가 아니라 Y`에서 X의 뜻을 Y로 추론하지 않습니다.
접두사·명사·접미사가 완전한 명사를 이룰 때만 묶고 조사·어미를 명사로 바꾸지
않습니다. 지원 어휘와 구문은 아직 제한적이며, 의미 선택 성공과 최종 발음 성공은
별도로 검증합니다.

정의·소속 관계의 병렬 명사구는 모든 성분이 공유하는 유형만 전달합니다. 알려진
법 분야와 미지·이질 분야가 섞이면 일부 성분만 골라 분류하지 않습니다. 계사·중립
관형절이 소비하지 않는 바깥 논항은 보존하며, 명시적인 내부 주어를 버려 정의를
성립시키지 않습니다. 직접 뜻풀이와 총칭은 실제 목적어·명칭·핵어 관계를 요구합니다.
`이르다`의 지칭 용례도 목적지·수신자나 일반 전언 용례와 구별합니다. 가격 비교는
한쪽 논항에서 독립적으로 확인한 가격 유형을 사용하고, 높거나 비싸다는 속성만으로
대상 자체를 가격으로 간주하지 않습니다.

범주·분야·가격 구간과 명칭은 선언된 구성에서만 유형을 전달합니다. 능동 분류의
목적어와 피동 분류의 주어를 실제 분류 보어에 연결하며, 범주의 소유자도 그 역할이
명시됐을 때만 연결합니다. 부정된 분류는 긍정 근거로 사용하지 않고 부정 근거를
보존합니다. 일반 책·제목·그림 작품은 내용물의 유형을 상속하지 않습니다. 문학작품의
상위 유형은 해당 동형어의 가능한 문학 뜻을 제약하며 모든 작품을 시로 분류하지 않습니다.

이 유형·정의 문법은 곤충·침구·물질·활동·강변 등 처음 세 계열에도 적용됩니다.
원소 같은 물리적 구성원의 직접 동일시와 해산물 목적어를 가진 채취 활동의 명사화도
구별합니다. 장소·지속·나이의 중립 수식은 논항과 실제 부착을 확인한 경우에만
보존하며, 미지 활동을 무조건 무시하지 않습니다. 유형·조사·술어의 원문 근거를
함께 유지하고, 단독 어휘 발음과 조사 결합 발음을 평가에서 구별합니다.

자연수 약수의 배타적 열거는 별도 구조로 보존하며, 1과 자기 자신이라는 표현만으로
1을 배제하거나 소수로 판정하지 않습니다. 정확한 개수 또는 서로 다른 약수라는
명시적 조건이 필요합니다. 임의 산술 증명, 문장 사이 대명사 참조, 모든 명칭·분류
핵어와 수식 구문을 해석하는 기능은 아직 없으며, 처리하지 못한 문맥은 유보합니다.

의미 근거는 절·문장부호·인용·HARD 경계를 넘지 않습니다. 상충하는 관계나 직접
연결된 미지원 관형절이 있으면 선택을 보류합니다. 이 보수적 처리는 무해하지만
미지원인 수식어에서도 적용 범위를 줄입니다. 현재 의미 목록과 술어 틀은 한정되어
있으며, 일반 구문 분석·대명사 참조·생략·복잡한 관형절 전체를 해석하지는
못합니다. 혼례 등 명시적 유형 정의도 선언된 어휘와 관계에 한정됩니다. 의미 보류 시 기존 음운 처리를 유지하므로 그 출력의
우연한 일치를 의미 선택 성공으로 계산하지 않습니다.

직접 소유 관계에서는 등록된 방향 수식어 뒤의 명사구 핵어까지 소유자를 유지합니다.
임의의 명사를 건너뛰지는 않으며, 더 큰 명사의 일부를 어휘 근거로 사용하지 않습니다.
신체 부위가 손상되는 관형절, 명시적인 사람 주어가 있는 활동 논항, 명사와 하/XSV의
결합도 선언된 관계에 한해 처리합니다. `찢/VV + 어/EC + 지/VX`처럼 분해된 분석은
허용된 정규형 구성일 때만 합쳐 원래 논항을 보존합니다. 다른 연결 어미나 보조
용언, 중간 명사·조사·HARD 경계를 투명하게 넘기지 않습니다.

물리량·함량·지형의 분류는 자체 작성한 한정된 어휘 사실입니다. 예를 들어 분자량은
완전한 명사구 핵어로, 염분·수분·당분은 물리 함량으로 등록되어 있습니다. 일반적인
특징·상태나 단순히 분으로 끝나는 표기를 같은 부류로 추정하지 않습니다. 이 분류가
누락되면 상충하는 관계를 놓칠 수 있으므로 어휘 범위와 구문 처리의 한계를 함께
검증합니다. 중립 형용사, 복잡한 관형절, 보조사로 표시된 논항의 일반 해석은 아직
완성되지 않았습니다.
사이시옷의 `Z_SIOT`도 표면형과 좌표를 유지하며 결합하므로, 같은 구간을 두 번
분석하지 않고 복합어 규칙과 제30항 규칙이 같은 경계 정보를 사용합니다.

기본 음운 단계는 표준 발음법의 일반 규칙과 형태소 의존 규칙을 합성합니다.
구개음화는 조사·접사·활용형 경계를 확인하므로 `곧이어`와 `굳이`를 구별합니다.
공식 고시의 비모호한 114개 예시는 `tests/fixtures/korean_official_examples.json`에
독립 정답으로 보관하며 런타임에서 읽지 않습니다. `korean/lexicon.py`는 분석기가
합쳐 놓은 어휘의 내부 구조, 한자어 여부, 어휘별 경음화 위치를 제공합니다.
완성 발음이 아니라 이 정보와 음운 규칙을 합성하므로 `발전은`, `경제발전`,
`의견란은`처럼 조사·접두 성분이 붙어도 규칙을 재사용하며 HARD 경계를 넘지 않습니다.
구조 복원은 형태소 양 끝이 확인된 범위에서만 수행하고 이미 조사·어미로 분석된
부분을 덮지 않습니다. `겉옷을 → 거도슬`은 실질 형태소 경계의 대표음화와 조사
앞 연음을 합성해 처리합니다.

`댓잎·뒷얘기`는 사이시옷 경계, `공업용`은 명사와 `-용/XSN` 경계,
`유들유들`은 반복 부사 구조에서 ㄴ 첨가를 판정합니다. `줄넘기`의 명사 파생 접미사
`-기`와 피·사동 접미사 `-기`는 구별합니다. `개미핥기`에서는 ㄾ의 ㅌ이 사라지기
전에 뒤 자음을 된소리로 바꾸므로 겹받침 단순화로 조건이 소실되지 않습니다.
제26항은 한자어로 확인된 형태소의 ㄹ 뒤 ㄷ·ㅅ·ㅈ에만 적용하며, 모든 명사에
확대하지 않습니다. 명사끼리 접한다는 사실만으로 ㄴ 첨가나 경음화를 확정하지도 않습니다.

철자와 현재 분석만으로 결정하기 어려운 6개 어휘·어간 발음은
`korean/official.py`에 별도로 남깁니다. 여기서 어말 대표음으로 저장한 받침은
조사 앞에서 기저 받침으로 복원합니다.
`밭이랑`은 온전한 명사 분석에서만 `반니랑`을 적용하고, `밭+이랑` 조사 분석의
`바치랑`과 구분합니다. `값있-`, `뜻있-`은 기저 받침을 유지해 활용형에도 적용합니다.
어휘 구조·한자어 속성의 미등록 항목과 분석 중의성은 여전히 한계입니다. 분석 실패 시
형태소 의존 규칙을 보류하고 진단을 반환하며, 예전 예시 치환표로 발음을 덮지 않습니다.
예를 들어 분석기 없이 `맑게`를 처리하면 입력을 유지하고 `complete=False`로 보고합니다.

통짜 원형의 고유 구개음화 속성은 `korean/intrinsic_boundaries.py`에서 완성 발음과
분리합니다. 현재 사실은 `곧이듣/VV`의 내부 경계 하나이며, 활용형별 발음은 저장하지
않습니다. 공통 경계 소비자는 정확한 원형·호환 품사·전체 어미와 대상 자모의 실제
소유를 확인한 뒤 기존 구개음화 규칙을 적용합니다. 불투명한 첫 활용 경계가 있어도
그 경계보다 앞인 변하지 않은 구간을 원래 범위에서 직접 확인할 수 있을 때만
국소 대응을 허용합니다. 이를 단어 전체의 표면 증명으로 승격하지 않습니다.
고유 어휘 사실 하나의 추가와 생산 규칙의 일반화 성과는 구별합니다.

제11항 다만의 용언 ㄺ 처리와 제24·25항의 어미 앞 경음화는 검증된 토큰 내부
어간·어미 경계도 소비합니다. 전체 문법과 원래 토큰의 강한 표면 증명, 어간 말음과
어미 초성의 단독 소유가 모두 확인되어야 합니다. 이 권한은 음운 변화 전에 고정하고,
실행할 때 현재 받침·초성을 다시 확인해 선행 규칙이 바꾼 받침을 되돌리지 않습니다.
명사형 어미와 허가된 `기/XSN`은 사동·피동 `기/XSV`와 구별합니다.
이 경로의 통제 검증은 기존 분석기 생성 지점에 고정 분석을 공급해 수행합니다.
공개 `G2P` 생성자에는 분석기 주입 인자가 없으며, 실제 Kiwi의 토큰 포장과 적용률은
별도로 관찰해야 합니다.

`출동·출전`은 한자어 속성으로 제26항을, `손길·갈대`는 내부 합성 경계로 어휘 경음화를
적용합니다. `날짐승`은 `날/VV+ETM + 짐승/NNG` 구조만 보충하여 기존 제27항을 사용합니다.
완성 발음이나 조사 결합형을 별도로 등록하지 않으므로 조사 앞 연음과 파생형에도 같은
속성을 재사용합니다. `물들다·열다`처럼 ㄹ 뒤 ㄷ을 된소리로 바꾸지 않는 경우를 유지하며,
철자만으로 모든 명사나 용언을 같은 경음화 조건에 넣지 않습니다.

`물질`의 고유어 잠수 채집 의미에는 `물/NNG + 질/XSN`과 통짜 `물질/NNG` 분석이
모두 가능합니다. 통짜 NNG라는 사실만으로 한자어 `物質`을 선택하지 않습니다.
의미 근거를 선택하지 못한 문맥에서는 여전히 `물질`의 `물찔`을 누락할 수 있습니다.
무조건 한자어 속성을 추가한 후보는 고유어 문맥을 잘못 바꾸어 수용하지 않았습니다.
단독 `물질·잠자리·강가`는 복수 표준 발음 중 하나를 낼 수 있으므로 원문 동일성을
보편 정답으로 강제하지 않습니다. 뜻이 정해진 문맥의 정확도는 별도로 평가하며,
`잠자리`의 침구 의미와 `강가`의 강변 의미도 위에 설명한 한정된 관계에서만 고릅니다.

이하 초기 검증 수치는 과거 기록이며, 현재 검증 대상은 Kiwi 0.24.1 하나입니다.
2026-10-25 초기 검증에서 kiwipiepy 0.23.2 기준 전체 2,675개 테스트를 통과했습니다.
조사 당시 고정한 진단 입력 465개 중 판정 가능한 457개는 426개에서 457개 정답으로
개선됐습니다. 알려진 결함과 규정 예시 중심의 자료이므로 전체 한국어 정확도를 뜻하지는
않습니다. Kiwi 0.24.1에서는 같은 진단 자료 456/457, 테스트 2,673개 통과·2개 실패입니다.
`서울역도`의 명사 분할과 단독 `밭이랑`의 명사·조사 선택 문제이며, 보존한 수정 전
소스에서도 같은 결과를 확인했습니다. 소스 전후 해시·정답 보존·실행 결과는
`output/g2p_rule_generalization_20261025/verification.json`에 기록합니다.

같은 날의 후속 개선에서 시험했던 외부 사전 기반 원어 자료는 MIT 배포 대상에서
제외했습니다. 자료와 전용 로더·전용 검사는 연구 기록으로 격리했으며 현재 실행 경로에
포함하지 않습니다. 현재 `korean/lexicon.py`의 불변 구조·품사·한자어 속성은 외부 자료를
읽지 않은 별도 구현자가 인터페이스 명세, 기능 평가 피드백과 자신의 언어 지식으로
작성합니다. 이 속성으로 `결석·골절·질서·질주·실적` 등에 같은 제26항 규칙을 적용합니다.
복수 품사와 한자 표기를 표현할 수 있지만, 표기와 품사가 같은 동음이의어의 뜻을
선택하는 기능은 아닙니다. 전체 한자어를 포괄하는 자료도 아닙니다.

독립 구현자는 기존 구현·테스트·외부 저장소·사전·연구 자료를 읽지 않고 지정된 명세와
자신의 후보 파일만 다룹니다. 평가자는 별도 프로세스에서 후보를 기존 엔진에 연결하고
진단 자료, 문법 대조군, 전체 회귀검사를 실행합니다. 부족한 후보에는 동작 요구만 돌려주고
수정을 요청하며 실패한 후보와 평가 기록도 보존합니다. `korean/boundary_policy.py`도
이 방식으로 작성한 ㄴ 첨가 경계 판정 함수입니다. 명시된 합성 경계에서는 올바른
명사 파생 접미사 XSN을 허용하고 조사·어미 경계는 구분합니다. 이 절차의 독립 작성
범위는 어휘 속성과 경계 판정 모듈들이며, 기존 음운 엔진과 연결 코드를 포함한 저장소 전체를 클린룸으로
다시 작성했다는 뜻은 아닙니다. 자체 코드의 배포 표기는 MIT이고 별도 설치되는
의존성에는 각자의 라이선스가 적용됩니다.

후행 ㄹ 성분의 분석 후보도 어휘 등록 여부와 독립적으로 찾습니다. 같은 단어 안에서
두 음절 이상의 기반이 가능한 ㄴ+ㄹ 경계를 만나면 형태소 분석을 요청하고, 실제
명사·접미사 분석에 따라 제20항 단서의 적용 여부를 결정합니다. 후보를 찾는 것만으로
비음화를 확정하지 않으므로 일반 어휘의 유음화는 유지합니다. 조사가 붙어 다른 후보가
우연히 생겨야만 접미사 규칙이 실행되던 누락을 보완한 것입니다.

이미 분리된 명사 후행 성분도 통짜 명사에서 복원한 성분과 같은 등록 정보를 사용합니다.
`korean/attachment_policy.py`는 독립 작성한 순수 판정 함수로, 검증한 두 음절 기반,
등록된 후행 성분의 표기·정확한 품사, 비음화 경계 속성, 알려진 한자 정보의 일치를
확인합니다. `등산/NNG+로/NNG`를 처리하기 위해 명사 태그를 XSN으로 바꾸지 않습니다.
조사·어미가 섞인 범위나 알려진 원어와 모순되는 후보는 이 경계의 근거로 삼지 않습니다.
`추진·해군·출연·수신·등산·이원`의 독립 작성 기반 속성은 기존 후행 성분과 합성하며,
각 파생어와 조사 결합형의 완성 발음을 별도로 저장하지 않습니다.

`량(量)`의 명사 품사와 `-문(文)`의 접미사 품사를 구분해 확인된 한자어 기반과
합성합니다. `발전량`의 [발쩐냥]은 독립된 두 음절 한자어 뒤 경계에 관한 제20항
해설에서 도출한 결과이며, 이 표제어의 공식 사전 발음을 직접 인용한 것은 아닙니다.
`결정문을`은 `결정`의 경음화와 뒤 조사 앞 연음을 합성합니다. 임의의 끝 글자만
보고 접미사로 나누지 않고 온전한 명사 분석·확인된 기반·HARD 경계를 검사합니다.
`생산량`의 내부 `량`도 잘못된 접미사 태그 대신 명사와 해당 경계의 음운 속성으로
표현합니다. `윗입술`은 윗·아랫·뒷의 사이시옷 결합형과 뒤 성분 경계를 이용하고,
`첫인상·첫인사`는 ㄴ 비첨가 어휘 속성, 대표음화, 연음 순서로 처리합니다.

독립 구현 교체 전의 후속 검증은 Kiwi 0.23.2에서 2,732개 통과, 0.24.1에서 2,730개 통과·기존 2개
불일치입니다. 기존 진단 자료는 각각 457/457과 456/457을 유지했습니다. 앞서
반례로 확인한 `결석·골절·질서·질주·윗입술·첫인상·첫인사` 일곱 사례는 두 버전의
실제 분석 경로와 Kiwi를 호출하지 않는 올바른 분석 통제 경로에서 모두 맞았습니다.
이것은 공개된 결함의 회귀검증이며 신규 평가나 전체 정확도 추정과 구별합니다.
후속 원시 결과는 `output/g2p_goal_cycle01_20261025/`에 보존합니다.

독립 구현 교체 후보와 재평가 기록은 `output/cleanroom_cycle01_20261025/`에 별도로
보존합니다. 앞선 버전의 통과 수를 새 후보의 검증 결과로 사용하지 않습니다.
`output/`과 내부 조사 문서는 wheel·sdist 배포 대상에서 제외합니다.

일반 공백은 이어 읽기가 가능한 경계로 취급하므로 `결실을 얻었다`는
`결씨르 러덛따`처럼 처리할 수 있습니다. 단어별로 끊어 읽는 발음과 비교할 때에는
이 정책을 평가 조건에 명시해야 합니다. 탭·줄바꿈·구두점 및 HARD 경계는 연결을
차단합니다. 띄어쓰기만으로 실제 발화의 모든 휴지를 결정할 수는 없습니다.

공개 단일 입력 메서드의 `pause_boundaries`는 NFC 입력 좌표를 영문 치환 뒤 좌표로
옮겨 음운 엔진에 별도로 전달합니다. 이 경계는 `HARD`와 달리 분석 island나 의미
선택 범위를 나누지 않습니다. 음운 전용 경계 검사를 일반 이웃 규칙과 직접 어휘·형태소
변경 경로가 공유하며, 경계를 넘는 소리 의존 관계만 차단합니다. 길이가 달라지는
영문 치환 내부의 휴지 좌표는 거부하고 원문 문자와 provenance는 유지합니다.

자체 음운 개선은 올바른 형태소 분석을 전제로 합니다. 분석기에서 관찰한 문제는
`docs/KIWI_ISSUE_LEDGER.json`에 제보 후보·조건부 관찰·중의성으로 구분해 누적하며,
`tools/record_kiwi_issues.py`가 직접 `tokenize()`·`analyze()` 결과, 버전, 모델,
상위 후보와 대조군을 기록합니다. 단어별 우회 규칙을 만들어 오분석을 숨기지 않습니다.
통짜 NNG의 올바른 어휘 분석에 내부 합성 구조를 보충하는 일은 오분석 수정과 구별합니다.

제10항의 밟·넓 예외, 제15항 실질 형태소 연음, 제16항 자모 이름의 예외 연음,
제27항 어미 내부 경음화와 제29항 이어 읽기를 처리합니다.
격음화 뒤에 제5항의 ㅕ 약화를 적용하므로 `묻혀 → 무처`도 한 번에 실현합니다.
외부 발음 사전을 통째로 탑재하지 않으며 문맥상 복수 해석이 가능한 어휘는 남을 수 있습니다.

`G2P.convert()`의 정규화 report는 원문과 빈 진단 목록을 갖습니다. 발음 report는
NFC 입력 기준 좌표를 사용하며 영문 확장 이후의 출력 좌표와 구별합니다.
미변환 숫자, 미지원 문자, 분석 실패가 있으면 `complete=False`입니다.

`G2P.__call__()`과 `G2P.convert()`는 같은 병합 segment와 음운 엔진을 사용합니다.
형태소 분석도 HARD 경계마다 분리하며, 후보가 있는 각 구간을 한 번 분석한 뒤
token 좌표를 전체 입력 기준으로 복원합니다. 따라서 보호 경계 너머 문맥이 구개음화나
어휘 예외 판정에 섞이지 않습니다.

형성평가·총괄평가·수행평가·진단평가는 전체 어휘의 내부 구성과 `평|가` 경음화
경계를 자료로 선언합니다. `LexicalStructure.owner_pos`가 있는 항목은 원 분석이
등록된 전체 명사를 정확히 덮는지 추가 확인합니다. 통짜 NNG·허용된 NNP와 연속된
NNG 분석을 지원하며, 붙은 다른 명사 조각이나 조사·어미를 내부 성분으로 덮지
않습니다. 이 검사는 해당 메타데이터가 있는 구조에만 적용합니다. 음운 규칙은 기존
경계를 재사용하므로 `형성|평가` 휴지와 `평|가` 휴지를 구분합니다. 이는 네 어휘의
검증된 구조를 보충하는 기능이며, 미등록 복합어의 의미를 자동으로 알아내거나
고립된 `평가`의 여러 뜻을 결정하는 기능은 아닙니다.
두 경로는 `korean/engine.py`의 같은 규칙 실행기를 사용하며, 문자열 경로는 호출별
원문 span과 `Rewrite`·`Diagnostic` 객체 생성을 생략합니다. 형태소 분석과 규칙 보류
결정은 추적 여부와 무관하게 동일하게 수행합니다. `korean/morphology.py`는 형태소
후보·분석 검증·형태소 의존 규칙을, `_shared.py`는 내부 음운 단위와 경계 연산을
담당합니다.

NFC 상세 경로는 정준 분해의 결합 등급과 인접 문자 조합을 확인해 원문 좌표가 단조인
원자 구간을 만듭니다. 한글 자모뿐 아니라 결합 등급이 0인 문자 사이의 정준 조합도
처리하여 문자열 경로의 표준 NFC 결과와 일치시킵니다. 기존 독립 노멀라이저에서만
경로·인라인 코드 보호 범위를 사용합니다.

## 문자 위치 대응

음운 엔진은 정규화문 문자를 삽입하거나 삭제하지 않습니다. 현대 한글 음절은 같은
위치의 현대 한글 음절로만 치환하며 공백·구두점·보존 문자는 위치를 유지합니다.
파이프라인은 segment별 길이와 전체 code point 길이를 내부 불변식으로 검사합니다.
API는 완료된 결과에서 다음과 같은 문자 위치 대응을 제공합니다.

```text
normalized_text[i] ↔ surface_pronunciation[i]
len(normalized_text) == len(surface_pronunciation)
```

## 공유 상태

- 정규식·규칙표: 모듈에서 한 번 컴파일
- Kiwi: 프로세스에서 지연 생성 후 재사용
- 외부 숫자 모델: 앞단 책임이며 G2P가 호출하지 않음
- 분석 결과·segment: 호출마다 생성, 상세 진단: `convert()` 호출마다 생성
- 사용자 사전: 기존 독립 노멀라이저에서만 생성 시 trie로 컴파일

배치 API는 순차 지연 iterator입니다. Kiwi의 `tokenize()`는 문자열 iterable을 받는
batch 분석도 지원하지만, 호출 시 입력 generator를 결과 요청보다 먼저 소비하고 뒤
항목의 형식 오류도 앞당길 수 있습니다. 현재 G2P는 정규화·라우팅 뒤 형태소 후보가
있는 항목만 분석하므로, 이 동작은 공개 API의 항목별 lazy 오류 시점과도 맞지 않습니다.
따라서 단순 `map`을 형태소 batch라고 부르거나 Kiwi batch로 넘기지 않으며, 각 항목의
기존 단일 변환을 순서대로 실행합니다. Python 스레드는 Kiwi 처리량을 높이지 못했으므로
내부 병렬 옵션을 두지 않습니다. 여러 코어가 필요하면 프로세스 워커를 사용합니다.

## 인용된 용어와 정확 수량 정의

의미 선택기는 짝이 맞는 인용 명사에 별도 원문 구간을 부여하고, 실제 격 논항과
긍정 정의·명명·분류 관계가 있을 때만 바깥 정의와 연결합니다. 용어·명칭 같은
핵어는 입증된 유형을 전달하며 책의 제목이나 단순 발화 보고만으로 뜻을 정하지
않습니다. 인용부호를 전역에서 지우거나 문장·HARD 경계를 해제하지 않습니다.
짝이 맞는 중첩 인용 안의 명사 용어 정의를 지원합니다. 여러 단어인 순수 명사 연쇄와
검증된 긍정 선행 관형절이 있는 인용 명사구도 정확한 핵어의 외부 정의에 연결합니다.

정확히 두 약수를 갖는다는 사실은 그 약수가 속한 자연수 핵어에 부착하고,
근사 수량·다른 수량·부정·별도 소유자의 관계로 소수 유형을 만들지 않습니다.
의견 차이 자체는 소수 집단의 증명이 아니며 독립적으로 입증된 수량 분류와만
함께 사용할 수 있습니다. 모든 처리는 올바른 형태소 분석을 전제로 합니다.

## 인용 명사구의 긍정 선행 관형절

닫힌 인용 안에서 완전한 용언·선어말어미·관형형 ETM 역할과 원문 덮임을 확인한
선행 관형절은 뒤의 순수 명사 연쇄를 수식할 수 있습니다. 명사와 관형절의 개수는
고정하지 않습니다. 남은 명사 연쇄의 정확한 표적 출현과 마지막 호환 핵어에 실제
바깥 정의가 연결될 때만 뜻 근거를 전달합니다. 관형절 내부 주어·목적어의 출현은
바깥 명사구의 소유자로 올리지 않습니다.

이 처리는 수식어를 뜻 단서로 삼거나 임의로 삭제하지 않습니다. 해당 표적에서 실제
정의가 입증되고 미지원 관형절 근거의 범위가 구조적으로 소유된 긍정 수식어 범위와
정확히 같을 때만 중립 소유 근거로 바꿉니다. 다른 표적이나 상충·부정 근거는 보존합니다.

부정 보조 용언·부정 명사 관형절·명사 연쇄 뒤 관형절과 복잡한 연결절은 여전히
제한적입니다. 인용 닫힘의 소유 검사는 이 문법 지원 여부와 별도로 적용합니다.
모든 관형절의 해석을 보장하는 문법 분석기는 아닙니다.

## 긴 부정 복합체와 명사 원천

실제 본용언·연결·보조 용언의 역할과 순서가 확인된 긴 부정 복합체에서는
읽기를 제한하는 어휘 제약과 사건의 실현·결과·새 유형 단정을 구분합니다.
허가된 출처의 제한은 남기되 부정된 사건의 결과를 긍정 사실로 만들지 않습니다.
한 출처의 여러 읽기는 대안으로 묶고 독립 출처의 제한을 함께 적용합니다.
중립 관찰과 읽기 제한을 새 명사 사실로 전파하지 않습니다.

직접 부분 소유, 병렬 명사구의 국소 속격과 가격 논항도 실제 역할·지지·소유를
확인합니다. 선택하지 않은 후보의 속성을 실제 모순 근거로 사용하지 않고,
완성된 앞 병렬항을 뒤 항의 국소 속격 때문에 제거하지 않습니다.

인식된 핵어와 일반 완전 명사는 같은 명사 원천 증명을 공유합니다. 여러 원래
토큰이나 공급 성분의 형태·태그·순번·좌표를 보존하여 부착·파생·복합체 소비자에
전달합니다. 실제 핵어 신원은 별도로 유지하며 접미사 재태깅이나 임의 명사 합성으로
증명을 대신하지 않습니다. HARD·인용·상충·필수 역할 검사는 계속 적용합니다.
지원하는 효과와 관계에 한정된 처리이며 모든 부정·유형/개체·신원 해석을 보장하지
않습니다.

## 인용 닫힘과 의미 근거의 소유

기존 열 쌍의 인용부호에 같은 원문 토폴로지를 사용하며, 중첩·불일치·교차·닫힘
누락을 확인합니다. 일반 선택·인용 재스캔·대조·파생 근거와 최종 결정이 이 상태를
함께 사용합니다. 표적이나 실제 참여 앵커가 미결 인용에 속하면 해당 출현의 뜻
선택을 유보하고 `unresolved_quote_ownership` 근거를 남깁니다. 뒤 경로가 이 유보를
덮어쓰지 않습니다. 단순 근접만으로 바깥 표적과 내부 앵커의 역할 연결을 만들지는
않습니다.

정상적으로 닫힌 여러 문장·여러 줄 인용은 허용하고 HARD마다 상태를 초기화합니다.
검증된 인용 명사구를 외부 정의에 연결할 때는 실제 참여한 명사 성분만 같은
소유자로 내보냅니다. 독립 범위와 시작 전 출현까지 일괄 유보하지 않습니다.
이 검사는 TYPE/ENTITY 판별이나 새로운 어휘 사실을 제공하지 않습니다.

## 명사구의 핵어와 중첩 인용 범위

의미 유형은 실제 명사 핵어와 그 핵어에 붙은 관계에서 합성합니다. 독립적으로
유형이 확인된 핵어에 비정의적 수식이 붙어도 그 유형을 유지하며, 책·그림·목록은
내포된 명사의 유형을 물려받지 않습니다. 범주 핵어의 유형과 수량 수식도 각각의
소유자를 확인합니다. 다른 명사구의 수량이나 부정으로 대상의 뜻을 정하지 않습니다.

중첩 인용은 짝이 맞는 포함 관계와 원문 좌표를 유지합니다. 내부 용어에 붙은
정의는 사용할 수 있지만 형제 인용·바깥 화제·전체 문장 보고의 뜻을 옮기지 않습니다.
HARD 경계마다 인용 상태를 초기화하고 교차·불일치 구간은 보류합니다. HARD가 없는
미완성 바깥 인용은 다문장 인용과 구별하기 어려워 보수적으로 보류할 수 있습니다.

## 정의와 명사구 관계의 합성

의미 선택기는 실제 명사 핵어와 연결된 범주·부분·수량·위치 관계를 조합합니다.
공유 핵어가 확인된 병렬 수식과 국소 정의를 처리하고, 정의되는 대상과 소유자·책·표제의
역할을 구별합니다. 낮은 인원수는 실제 부분 집단에, 약수 개수와 소수점 아래 자리는
실제 수 핵어에 붙어 있을 때만 사용합니다. 사법 기능의 주어·재판 수단·법 적용과
물체의 구성 바탕, 사람의 누움·잠듦 장소도 유한한 관계 틀로 확인합니다.

형태소로 나뉜 복합 명사는 허용된 어휘 구성·정확한 인접 경계·원문 표면이 일치해야
하나의 의미 단위로 조립합니다. 사이시옷 성분도 같은 조건을 따르며 원래 분석 태그와
메타데이터는 바꾸지 않습니다. 일반 수량사나 떨어진 명사를 임의로 합치지 않습니다.

명시적인 부정 대조 뒤 쉼표는 그 정의의 국소 연결로만 처리합니다. 일반 쉼표·문장·인용·
HARD 경계를 일괄 해제하지 않으며, 서로 다른 출현의 뜻이나 다른 생물의 부분 소유를
옮기지 않습니다. 문장 간 참조와 모든 정의 표현을 해석하는 범용 의미 분석기는 아니며,
지원되지 않은 관계에서는 의미 선택을 보류할 수 있습니다.

## 구성원 정의와 명명·보고의 역할 보존

구성원을 묶거나 포함하는 관계는 실제 목적어와 호환되는 명사 핵어에 연결합니다.
내부 관형절에 명시적인 행위자가 있어도 바깥 정의의 주어·화제를 제거하지 않습니다.
체계는 법 유형이 독립적으로 확인될 때만 해당 구성원 정의를 받을 수 있으며, 책이나
표제·혼합된 구성원만으로 같은 뜻을 만들지 않습니다. HARD가 자른 병렬 관계도 보류합니다.

계사와 연결 어미로 분석된 명명 표지는 상위 용언이 확정될 때까지 원래 주어·화제와
내포절 후보를 함께 보존합니다. 보고 용언이면 실제 내포 계사 주어·보어만 연결하고,
명명 용언이면 원래 명명 주체를 유지합니다. 설명한 사람의 역할을 정의 대상에 옮기지
않습니다. 이 처리는 역할과 국소 관계에 적용하며 완성 문장별 예외를 사용하지 않습니다.

## 어휘 경계 속성과 일반 조사 결합

민법·헌법·형법은 확인된 내부 경음화 경계만 어휘 속성으로 선언합니다. 기본형이나
조사별 완성 발음을 저장하지 않으며, 종성 연음·비음화·뒤 장애음의 경음화는 기존 일반
규칙이 합성합니다. 모든 법 말미 명사를 경음화하지 않고 방법의 내부 평음을 유지합니다.
뜻이 지정되지 않은 불법은 기존 허용 평음 경로를 유지하며 상법의 뜻별 처리는 별도입니다.
속성은 검증된 어휘 범위에 적용하고 HARD 경계나 더 긴 미확인 전체 토큰의 내부로
확장하지 않습니다. 반복 출현의 추적 좌표도 각각의 원문 구간을 소유합니다.

## 뜻별 수량·능력 관계와 명사 내부 구개음화

개수와 말발의 동형어는 뜻별 속성을 선언하고, 실제 수량 논항·수량 질문·능력 병렬
소유 관계에서 확인한 뜻에만 경음화 경계를 적용합니다. 단독 표기나 주변 단어의
근접만으로 뜻을 확정하지 않습니다. 능력 병렬 관계는 보조 명사의 직접적인 어휘 핵어
증거를 요구하며, 미해결 수식·상충 정의·소유 범위는 계속 선택을 막습니다.

명사 내부 구개음화는 `palatalization_policy.py`의 경계 자료로 선언합니다. 접두 범위,
접미 범위, 정확한 전체 명사와 허용 품사를 구분하고, 전체 소유 범위를 검증한 뒤
기존 음운 규칙에 경계 정보를 전달합니다. 붙임머리는 등록된 내부 경계를 사용하며
원래 분석 품사나 형태소를 바꾸지 않습니다. 기존 파생 명사의 문자열 분기도 같은
자료 경로로 모았습니다. 휴지·HARD 경계와 미확인 전체 명사의 보호 조건은 유지합니다.

## 원문 정렬과 단어 경계의 어휘 품사

공개 `convert_with_alignment()`은 기존 변환 결과와 원문 좌표 정렬을 함께 반환합니다.
NFC provenance와 동일 실행의 정규화·발음 segment를 합성합니다. 영문 치환과 정준
조합 묶음은 작업 단위로 추적하며, 원자적 범위의 일부만 요청하면 명시적으로 거부합니다.
출력뿐 아니라 원문 전체의 대응도 검증하고 근거 부재는 별도 상태로 표시합니다.

단어 경계 ㄴ 첨가는 독립 부사를 어휘 대상으로 포함하며, 계사의 문법 범위는 구분합니다.
용언의 규칙·불규칙 하위 태그와 어간·어미가 겹친 분석은 원 형태소의 종류와 순서를
확인합니다. 특정 부사나 활용형의 완성 발음을 저장하지 않고 기존 첨가·동화 규칙을
재사용합니다. 원래 형태소 증거가 없는 혼합 태그와 미지 태그는 적용 근거로 쓰지 않습니다.

`word_grammar.py`는 파생·유형별 어미·조사·계사·보조용언 전이를 판정하는 순수한 공통
핵심입니다. `word_roles.certify_word()`는 적격·제외·미해결을 구분하고, 어휘 범주와
전체 문법·정확한 자모 소유의 권한을 각각 기록합니다. 약한 전체 표기 실현이나 실제
용언의 제한된 첫 활용 구간은 범주 근거를 줄 수 있지만 강한 자모 소유를 만들지 않습니다.
접두 파생의 어휘 자격은 정확한 품사의 자동 승계와 다릅니다.

내부 성분 연음은 별도로 확인한 실제 인접 토큰 범위만 사용하며 외부 단어 근거를
대신하지 않습니다. 이미 확인된 어근 내부 속성은 불확정 바깥 구문과 구분합니다.
부분 수신 범주와 내부 속성의 권한으로 전체 부착·계사 예외·어휘 신원을 허가하지 않습니다.
옛 파생 역할 API는 단일 어휘 핵심과 완전한 꼬리를 요구하며 보조용언 사슬에서 앞
접미사를 마지막 보조용언의 파생 원인으로 반환하지 않습니다.

## 경구개음 뒤 j계 모음 표기

`rules.py`의 작은 성분 대응표로 ㅈ·ㅉ·ㅊ 뒤 여섯 j계 모음의 정규 발음 표기를
처리합니다. ㅒ·ㅖ는 공식 j계 모음 구성과 경구개음 제약에서 도출한 대응입니다.
기존 이른 ㅕ 처리는 `ko.vowel.jyeo`를 유지하고, 연음·경음화 이후 마지막 통과가
추가 모음과 뒤늦게 생긴 초성에 `ko.vowel.palatal_j_canonical`을 적용합니다.
바뀔 성분이 없으면 다시 rewrite를 만들지 않습니다. 초성·종성·음절 수와 출처는
유지하며 보호 문자열이나 미변환 영문을 전체 문자열 치환으로 처리하지 않습니다.

선택적 장음 정보의 모음 핵은 정확한 지역 정렬과 해당 음운 규칙 귀속이 확인될 때만
표기 변경을 허용합니다. 이른 ㅕ 변경 뒤 다른 음운 규칙이 최종 정렬 귀속을 덮는
기존 경로의 미확정은 남아 있으며, 이 규칙의 수용을 전체 장음 정렬 완성으로 보지 않습니다.

## 형태소 역할을 공유하는 내부 경계 규칙

`boundary_consumers.py`는 제15항의 실질 접미 성분, 제17항의 형식 이·히,
제29항의 명사 내부 경계를 구분합니다. 실행 전에 문법과 원형 자모 소유를 확인하고,
실행할 때 현재 음운 상태에 적용합니다. 기존 완성 발음 대체는 먼저 실행하며
새 규칙이 그 결과를 원래 받침으로 되돌리지 않습니다.

제17항은 축약 전 이·히와 공유 표면 증명의 실제 변환 단계를 사용합니다.
과거 어미도 첫 원형 모음으로 확인하며 특정 활용형 문자열을 열거하지 않습니다.
문법 근거는 실제 HARD·보호 구간 안에서 확인하고, 휴지는 적용할 인접 음절 경계에서
검사합니다. 뒤쪽 휴지가 앞쪽의 독립적인 문법 결합까지 지우지 않습니다.
이 내부 성분 권한은 공개 단어 경계 인증의 범위를 넓히지 않습니다.

통짜 분석의 내부 형식 접미사는 V 품사나 철자만으로 만들지 않습니다. 필요한 경우
확인된 최소 어휘 구조 사실을 별도로 선언합니다. 완성 발음 대신 원형·경계·역할을
저장하지만 어휘 자료가 필요하다는 한계는 남습니다. 구조가 없는 실제 단어의 이전
발음 지원이 손실될 수 있으며, 이 한계를 Kiwi 결함이나 비구개음화 정답으로 취급하지 않습니다.

## 생산적 준말과 완전 삭제 출현

공유 표면 증명은 제40항의 앞 받침 소릿값에 따른 하 삭제·격음축약 후, 제39항의
정확한 지/EC·않/VX 결합을 합성합니다. 이는 관측된 준말을 재생성하는 기능이며
본말 입력의 발음을 임의로 줄이는 기능은 아닙니다. 어미와 원형 출현의 신원을 유지합니다.

`TokenSurfaceProof.deleted_occurrences`는 모든 자모가 사라진 출현을 원래 신원,
삭제 자모, 규칙과 유일한 절대 경계로 설명합니다. 해당 `regenerated_spans` 값은
None이며 살아 있는 영폭 범위를 만들지 않습니다. 최종 생존 원자와 삭제 원자는
겹치지 않고 전체 원형 자모를 설명해야 합니다. 단순 영폭 표지나 표기 가능성은
이 강한 소유 증명을 대신하지 않습니다.

현재 토큰 단위 증명에 없는 앞 토큰의 문맥을 임의로 가져오지 않습니다. 실제 분석의
여러 토큰을 합친 강한 범위 증명은 별도 과제이며, 문자열을 붙였다는 사실만으로
원래 토큰·범주·합성 구조의 근거를 새로 만들지 않습니다.

## 명시 불규칙 유형과 반증의 근거

표면 증명은 정확한 -I 표지와 활성 어간의 바로 다음 어미를 확인한 뒤 단일 ㄷ의
ㄹ 교체와 ㅅ 탈락을 처리합니다. 공급된 ㅇ+ㅏ·ㅓ·ㅡ 어미와 나머지 자모를 보존하며,
무표지·-R·다른 이형태·숨은 으를 추정하지 않습니다. ㅅ 탈락 뒤 같은 경계의 모음
축약을 자동으로 연쇄 적용하지 않습니다. 교체 ㄹ의 유래는 원래 ㄷ이고 삭제 ㅅ은
생존 자모의 소유에서 제외합니다.

강한 표면 증명이 없을 때 규칙 후보가 존재한다는 사실만으로 모순을 선언하지 않습니다.
실제 전체 표면을 재생성한 유일한 근거가 원형 자모와 삭제를 설명하고, 변하지 않은
어근의 독점 위치와 다른 형태소의 정확한 범위가 충돌할 때만 소유 반증으로 사용합니다.
어근 범위가 다른 성분의 공유 음절에 들어가는 경우와 다른 성분의 범위가 어근을
덮는 경우를 구별해 검사합니다. 원시 범위의 부재·미확정과 양의 모순은 별개이며
이 분류로 강한 자모 증명 자체의 정확 범위 조건을 느슨하게 만들지 않습니다.

## 소유 계수량을 기준으로 한 분류

한 명사구의 소유자와 계수 핵어, 실제 `에/JKB + 따르/VV + 연결 어미`, 뒤의
분류 사건과 선언된 분류·등급 핵어가 함께 있을 때 수량 뜻의 근거를 만듭니다.
직접 명사 수식과 명시적 속격을 같은 소유 관계로 소비하며 소유자별 단어 목록을
추가하지 않습니다. 선택된 뜻의 기존 어휘 속성과 공통 음운 규칙으로 발음을 만듭니다.

목적격이 생략된 분류 결과는 분류 서술어 바로 앞의 유일한 적격 명사구일 때만
무표지 논항으로 보존합니다. 실제 없는 조사를 생성하지 않습니다. 독립 장소의
`에서`와 기준의 `에`를 실제 조사로 구분하고, 경쟁하는 기준이 여럿이면 선택하지
않습니다. HARD·인용·절 경계와 반복 출현의 소유 범위를 유지합니다.

`나누/VV`의 분류 뜻은 이 결합 안에서만 소비합니다. 뜻 구분의 언어 근거는
[한국어기초사전의 나누다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=29749&nation=eng&nationCode=6)입니다.
위 결합 전체를 사전이 정한 규범이라고 주장하지 않으며, 제한된 문맥 의미 정책으로
사용합니다. 기준 표지만 있는 입력과 실제 동사 파생 사건에 수량 뜻을 강제하지 않습니다.

## 조사 모음의 기본 실현과 물리 토큰 포장

기본 조사 모음 소비자는 기존 단일 조사 토큰 경로를 유지합니다. 병합 토큰에서는
전체 표면 증명과 해당 중성 원자의 유일한 실제 조사 소유가 모두 확인될 때만 같은
규칙을 적용합니다. 결합 태그에 조사 표지가 포함됐다는 이유만으로 어휘 내부 모음을
바꾸지 않습니다. 원문 좌표·추적·다른 출현의 소유는 유지합니다.

## 방향 있는 유형 부정

유형 부정은 원래 주어/화제와 보격 조사가 있는 유한 부정 계사, 유일한 명시 주어와
별도 화제 범주의 역전형, 명시 내부 주어가 없는 관형형의 실제 후행 핵어에 한해
방향을 확인합니다. 독립적으로 유형이 선언된 일반 범주만 소비하며 원래 태그를
바꾸거나 보어와 주어에 부정을 대칭 복사하지 않습니다.

같은 유형의 독립 긍정·부정이 충돌하면 유보합니다. 다른 유형의 부정은 기존 긍정을
보존하며 부정만으로 남은 뜻을 선택하지 않습니다. 명확한 개체의 비동일성은 유형
부정과 구분하고, 미해소 참조는 영향을 받는 출현만 유보합니다. 일반·이중 부정과
새로운 빈자리 소유까지 지원한다고 해석하지 않습니다.

## 판단과 통화 기준 비율의 정의

실제 가치·수준 목적어를 판단하는 관형 사건이 독립 판단 핵어를 수식할 때 해당
명사구의 판단 유형을 구성합니다. 통화 정의는 실제 통화 값의 소유자, 실제 기준
논항과 비율 연산 또는 독립적인 소유 비율 명사구가 있어야 합니다. 금전 어휘의
근접만으로 뜻을 선택하지 않습니다. 구성한 유형은 실제 긍정 계사 정의로만 대상에
전달하며, 바깥 계산 행위의 부정을 안쪽의 독립 정의 부정으로 바꾸지 않습니다.

닫힌 인용의 사건 명사 설명에서도 내부 관계가 먼저 증명된 실제 명사 원자만
명시적 긍정 뜻 정의 포장으로 전달합니다. 제목·미완성 인용이나 임의 외부 화제로
유형을 내보내지 않습니다. 인용 안쪽의 원래 성분·좌표와 도출 근거를 유지합니다.

일반 가격 수식은 실제 국소 형용사 병렬과 쪽 핵어, 실제 위치 논항의 편향 수식,
독립적으로 완성된 가격 명사구를 각각 소비합니다. 기존 선언으로 완성할 수 있는
명사구를 먼저 구성한 뒤 관형 수식을 붙이며, 확인된 명사 원천은 단독·결합 태그의
포장과 무관하게 같은 핵어 판별 기준을 적용합니다. 대상의 가능한 뜻으로 소유를 정하거나
전체 미래 문장 패턴을 맞춰 예외를 허용하지 않습니다.
