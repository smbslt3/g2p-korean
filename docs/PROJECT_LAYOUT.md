# 로컬 프로젝트 폴더

이 저장소는 전체 TTS 노멀라이저와 한국어 G2P를 관리한다.
숫자 읽기 모델의 데이터·연구 코드·학습 환경·모델 산출물은 별도 프로젝트에서 관리한다.

| 경로 | 역할 |
|---|---|
| `src/g2p_ko/` | 전체 TTS 노멀라이저와 한국어 G2P |
| `src/g2p_ko/korean/` | 한국어 음운 규칙·형태소 경계·어휘 및 문맥 속성 |
| `src/g2p_ko/normalizer/` | 숫자·단위·기호·영문 정규화 |
| `src/g2p_ko/english/` | 영문 읽기 분류와 관용 표기 |
| `src/g2p_ko/number_normalizer.py` | 기본 G2P의 숫자 전처리 더미: 입력 그대로 반환 |
| `src/g2p_ko/number_reader.py` | HF 모델·추론 코드의 다운로드·무결성 검증·연결 |
| `tests/`, `tests/fixtures/` | G2P·정규화·외부 숫자 읽기 연결 및 고정 회귀 자료 |
| `tools/` | 벤치마크·배포물 검사·발음 구간 평가·Kiwi 제보 기록 도구 |
| `docs/` | API·구조·외부 모델 연결 방법과 경로를 고정한 조사·제보 문서 |
| `.github/` | CI 설정 |
| `pyproject.toml`, `uv.lock` | 패키지·개발 의존성과 고정 버전 |
| `LICENSE`, `NOTICE` | 자체 패키지의 라이선스와 고지 |
| `.venv/` | 현재 G2P 패키지의 로컬 개발·테스트 환경 |
| `benchmarks/` | G2P 성능 측정 결과 |
| `ignores/` | 로컬 조사·설계 메모 |
| `output/g2p_current_status.json` | 현재 수용본·미완료 항목·진행 순회의 진입점 |
| `output/README.md` | 로컬 산출물의 역할·현재 상태·압축 자료 복원 안내 |
| `output/<작업명>_<날짜>/` | 독립 작성·평가·실패 후보·로그·원본 연결·해시 기록 |
| `output/_archives/` | 펼친 중복 자료를 대신하는 검증된 로컬 복원 보관본 |

배포 런타임은 별도 학습 프로젝트의 파일이나 데이터를 직접 읽지 않는다.
로컬 조사 도구는 작업에서 명시적으로 허용한 원본을 읽을 수 있으며, 그 연결과 결과는
`output/`에 기록한다. `output/`, `benchmarks/`, `ignores/`, `.venv/`는 로컬 전용으로
Git과 배포물에서 제외한다. 이 문서의 `output/` 경로는 저장소 작업본에서만 유효하다.

HF 게시 전에는 검수용 로컬 배포 묶음을 명시적으로 지정할 수 있다.
HF 게시 후에는 저장소 ID와 고정된 커밋으로 동일한 묶음을 받는다.
기본 G2P는 숫자 더미를 실행하며 모델 다운로드를 요청하지 않는다.
별도 `KoreanTTSNormalizer`는 기존 숫자 형식 규칙을 유지한다.

## 구조 유지와 정리 기준

코드는 `src/`, 검증은 `tests/`, 명령형 도구는 `tools/`, 문서는 `docs/`에 두는 현재 구성을
유지한다. 조사 문서·시험 파일·순회 산출물의 기존 경로는 증거와 해시 기록이 참조하므로
그룹 이름을 바꾸거나 대규모로 이동하지 않는다. 로컬 산출물은 `output/README.md`로 찾는다.

현재 가상환경·빌드에 필요한 캐시·사용 중인 비교 구현 경로와 고유한 로그·정답·실패 후보·
라이선스 자료는 유지한다. 삭제 요청은 대상 경로와 현재 사용 여부, 보존 필요성을 간단히
확인한 뒤 휴지통으로 이동한다. 삭제를 위해 별도 해시 검사나 압축 보관 절차를 만들지 않는다.

`evaluation_source_pool`과 `private_evaluation_pool`은 평가 전용 접근 경계를 유지한다.
폴더 정리 시에도 본문을 열지 않고 삭제 대상에서 제외한다. `.git/`과 에이전트·
계정 설정 폴더는 보호하며, 현재 `.venv/`는 제거하지 않는다.

바이트코드와 테스트 캐시는 재생성할 수 있다. 정리 결과는 간단히 요약하고, 권한 오류가 난
경로는 실제 잔존 여부를 알린다. 휴지통 이동에 실패한 대상을 영구 삭제로 바꾸지 않는다.
